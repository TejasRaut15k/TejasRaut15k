## Featured projects

### [Sonar Radar System](https://github.com/TejasRaut15k/sonar-radar-system)
A browser-based radar visualization for robotics, designed to work with an ESP32 and ultrasonic sensor over WebSockets. Includes object tracking, proximity alerts, and simulation mode.

### [Quadrotor Studio](https://github.com/TejasRaut15k/quadrotor-studio)
An interactive MATLAB quadrotor simulator with URDF visualization, PID control, and a 3D flight view.

### [e-Yantra 2026: StrataCobot](https://github.com/TejasRaut15k/e-yantra)
ROS 2 competition work covering ore detection, Gazebo simulation, UR7e waypoint navigation, and singularity mitigation. See the `task-1a` and `task-1b` branches for the task implementations.

### Industry testing kits
